## Important discoveries and decisions

- Existing tag-driven GitHub release automation has previously produced both macOS
  architectures and checksum assets successfully.
- Release publication must remain a prerelease until broader product and distribution
  hardening are complete.
- The GitHub workflow, not the local arm64 build, is the source for published arm64 and
  Intel artifacts.

## Unresolved risks

- GitHub Apple signing secrets could not be verified locally.
- Published artifacts still require post-workflow checksum, asset, and signing-state
  verification.
- Clean-machine launch testing is not available in this local preparation step.
- Installed Kimi/Qwen and remote OAuth MCP fixtures remain external validation gaps.
